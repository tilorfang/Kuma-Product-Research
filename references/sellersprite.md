# 卖家精灵取数与口径

## 界面选择和启动检查

使用 agent 内置浏览器，先检查其登录和授权状态，再选择能读取本次字段的卖家精灵界面。不得因外部浏览器已登录而自动切换。网页适合关键词、商品研究、市场分析、历史趋势和建议竞价；插件适合商品查询、变体比较及页面销量/评价信息。名称和能力以当前可见界面及账号权限为准，不保证所有模块均可用。

用实际目标检查网页登录、站点、查询结果；插件须实际加载目标字段才算可用。记录到 `normalized/access.json`，含网页和插件各自状态、时间、阻塞及替代路径。不因一种界面不可用否定另一种；缺目标标未验证。普通加载故障可合理重试一次，权限/验证码不反复刷新。

内置浏览器能实际加载插件时才使用插件；无法加载时优先用同一内置浏览器的卖家精灵网页版互补。网页可满足需求就直接使用。不能操作插件时接受卖家精灵导出或截图，记录原文件、导出时间、筛选和范围，不清楚的字段保持未知。截图缺站点/范围时核最影响判断的缺项，不猜。

可打开 Amazon 商品页承载插件，报告可提供商品跳转链接；默认市场数据采卖家精灵可见面板或其导出；用户明确配置的数据MCP按 [mcp.md](mcp.md) 互补，不另行抓取无关平台。外部法律/合规核查列为待验证行动，不宣称本轮已完成。

## 按问题取数

| 判断问题 | 可见模块 | 缺项互补方式 | 关键检查 |
|---|---|---|---|
| 身份、装数、适配 | 商品研究或插件商品查询 | 变体对比、同来源导出 | 当前ASIN、父子体、型号和装数 |
| 目标/竞品近月销量 | 商品研究或插件销量估算 | 销量详情、变体对比、导出 | 子体还是共享父体；自然月还是近30天 |
| 销量历史 | 历史趋势/销量详情 | 对应网页/插件、历史导出 | 上架以来月份、日期轴、数值/档位 |
| 需求与季节性 | 精准词/长尾词及历史搜索量 | ASIN反查后核词、关键词导出 | 精确词与词根、站点、周期 |
| 竞品与新品进入 | 商品研究筛选、插件对比 | 可比样本导出 | 同规格/装数价格、上架时间、品牌 |
| 建议竞价 | 关键词竞价字段 | 网页关键词详情或导出 | 币种、更新时间；不是实际CPC |
| 评价痛点 | 评论分析/下载或插件可见内容 | 同来源评价导出 | 原文、变体、样本；不推测频率 |
| 包装、FBA | 商品研究/插件费用字段 | 用户实包/报价作为业务输入 | 整套包装非裸尺寸；日期币种 |

标准分析取约5–12个高相关词、5–10个直接竞品；目标及2–3个代表竞品深入历史和评价。数量按实际可得样本调整。核心词、功能词、场景词、型号/兼容词分别标相关性，不机械凑数。

## 不得混用的字段

- 月销量估算不是真实订单。变体共享BSR时，插件近30天销量可能属于父体；不自动分摊成子体。
- 父体单列“父体参考”，不同规格子体不拼接。网页/插件差异先核站点、周期、变体和刷新时间，不平均或择高。
- 购买档位如 `<50`、`100+` 原样显示，不取中值画柱；只有本款可核口径数值估算/实售序列能画本款柱形。
- 缺失不是0，不画上架前零柱。无历史可保留近月数值/档位，说明观察期不足。
- 搜索量、流量、主机销量、耗材销量不同；主机趋势只是替换需求线索。
- 建议竞价不填入 `actual_cpc_usd`。无实际CPC保持未知；配假设转化率只形成情景广告成本。
- 包装为整套实包；竞品包装可作明示情景，不称自家实测。报价与成本区间属于业务输入。

## 缺口按决策影响处理

每个**当前阶段**会改变判断的字段记录 `coverage`：target、field、critical、status、available、source_ids、attempts、next_action、decision_impact。状态为 `available/partial/not_queried/no_data/blocked/not_applicable`；只有实际查询无返回才写 no_data。

先查对应明细而非只看摘要。另一界面或导出可解决关键缺口且可访问就继续互补；无可行路径说明阻塞。标准模式必须尝试销量历史、关键词及趋势、竞争、评价；不能以已有方向判断代替尝试。简要模式可按用户范围省略并记not_queried。关键partial说明影响；模块访问受阻时完成其他可用模块，并将整体标为partial。建议竞价属于可选竞争线索，实际CPC不可强求。

## 原始记录与文件

每条市场记录至少含字段/值/单位、站点、ASIN或关键词、周期、获取时间、页面或导出文件、父子体范围、估算属性；人工读取可存JSON/表格，截图不能替代字段口径说明。

`raw/` 原始截图/导出/可见字段记录 → `normalized/` 口径及coverage → `research.json`。计算另生成利润输入与结果。稳定来源ID如S01贯穿派生结果，派生值写公式与输入来源。不保存密码、cookies、认证URL或无关个人信息。

来源渠道为 `sellersprite_web`、`sellersprite_plugin`、`sellersprite_export`；截图/导出仍是卖家精灵来源，不能假称本次已登录实查。`user`仅为成本/报价/包装等业务输入，不能绕过市场来源限制。详情折叠，影响当前判断的缺口与风险保持可见。


## 效率与完成状态

优先列表/批量对比及可见导出；复用已读取记录，不为图表再查同一字段。每模块记录elapsed_seconds、page_visits、status、attempts和限制。页面访问次数指进入页面、查询结果或明细面板的次数，不是每次观察。计时仅含该模块实际取数整理，不把其他开发等待计入。无法精确记录可填null并说明，禁止编造性能数据。

初始“暂无数据”可能为加载态：等待下一次有效界面观察，再确认数据、权限或错误。历史明细/子体历史/关键词明细是优先互补路径。字段冲突保留两边值和时间，不择高；上市日期与更早历史冲突时保留原始记录，不能直接推断该子体上市前销售。

module_status包含sales/keywords/competition/reviews/economics。standard的前四项不得not_queried；blocked/no_data须有具体attempts和reason。只完成尝试不等于证据齐备；任一必需模块partial/blocked/no_data，整体research_status=partial。只有前四项available才可completed（仍需分析者检查充分性）。

## ASIN主图覆盖

主图与基础信息同批采集，覆盖本次报告出现的目标、竞品及参考ASIN，优先目标和展示销量/差评的代表竞品。在agent内置浏览器中先看卖家精灵列表/批量对比图，再查缺图ASIN的产品详情、图像预览或同源可用导出；已有对应图片不重复访问。网页不提供保存、但可见主图时，可用浏览器支持的截图方式保存清晰商品区域，注明截图来源；不得用无关整页截图冒充主图。插件仅在内置浏览器确实可用时操作，否则使用卖家精灵网页互补。

核对站点、ASIN和变体/规格，父体图不能未经核实用于子体。只保存工具允许获取的实际来源图片至raw/images，填写products[].image_file和image_source_ids；同一ASIN复用一份离线图片。不得猜测图片URL、绕过浏览器媒体限制或转其他平台补图。

交付前按products清点主图覆盖，缺图尽量完成一次可用同源互补；coverage中以field=商品主图记真实attempts、状态和原因。该项通常critical=false，不因图片受阻拖住市场分析。确实不可取得才显示“暂无主图”，不声称已补齐。

用户接入的数据MCP可作可选互补渠道，详见 [mcp.md](mcp.md)；不要把MCP结果标为卖家精灵网页实查。
